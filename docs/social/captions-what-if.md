# PolTok "What if…" series: post copy

Every number comes from real data: the VEC's 2022 Victorian results, the latest polls on Wikipedia, the AEC referendum results, and the UK's 2024 turnout. Where a reel is a what-if, it is arithmetic on real votes, not a prediction, and it says so on screen.
